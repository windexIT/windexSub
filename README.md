# Battle IP Overlay

Android-приложение для эмулятора/телефона, которое берёт поток пакетов из PCAPdroid и показывает найденный IP батл-сервера Brawl Stars в плавающем окне поверх игры.

## Как это работает

1. Приложение запускает свой foreground-сервис и плавающее окно.
2. Через публичный Intent API PCAPdroid запускается в режиме `udp_exporter`.
3. PCAPdroid фильтрует захват по пакету `com.supercell.brawlstars` и отправляет PCAP-пакеты на `127.0.0.1:5123`.
4. Сервис приложения слушает UDP-порт, парсит IPv4/IPv6 пакеты и выбирает внешний адрес как IP сервера.
5. Оверлей остаётся поверх Brawl Stars, поэтому переключаться в PCAPdroid во время игры не нужно.

## Первый запуск

1. Установи PCAPdroid и Brawl Stars на тот же Android/эмулятор.
2. Собери и установи это приложение из Android Studio или командой `gradle :app:assembleDebug` в окружении с Android SDK.
3. Открой **Battle IP Overlay**.
4. Нажми **Разрешить окно поверх игры**.
5. Если хочешь запускать захват без диалога PCAPdroid, сгенерируй API key в PCAPdroid: **Settings → Control Permissions → меню → Generate API key** и вставь его в поле приложения.
6. Нажми **Запустить оверлей и PCAPdroid**.
7. Если PCAPdroid попросит разрешение на захват, разреши его один раз.
8. Нажми **Открыть Brawl Stars** и играй — IP будет обновляться в оверлее.

## Важные детали

- Захват ограничен пакетом Brawl Stars: `com.supercell.brawlstars`.
- UDP-приёмник слушает порт `5123`; если он занят другим приложением, сервис покажет ошибку.
- PCAPdroid должен быть установлен: приложение использует его API, а не пытается перехватывать чужой трафик самостоятельно.
- Поле API key необязательно, но помогает запускать захват без повторного диалога разрешений PCAPdroid.
- На Android 13+ приложение запросит разрешение на уведомления, потому что сервис работает как foreground-service.
